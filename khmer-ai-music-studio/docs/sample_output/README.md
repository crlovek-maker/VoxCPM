## ⚠️ សូមកត់សម្គាល់

- **ពេលខារ៉ាអូខេក្នុង MP4 នេះមិនត្រូវនឹងពេលច្រៀងពិតទេ** — តេស្តស្វ័យប្រវត្តិចុចកំណត់ពេលឃ្លាទាំង ៤ ក្នុងចន្លោះស្មើៗគ្នា (ត្រង់ 1.2, 7.9, 14.6, 21.3 វិនាទី)
  ដើម្បីបង្ហាញថា pipeline ដំណើរការប៉ុណ្ណោះ។ ការតម្រឹមពិតគឺជាការងាររបស់អ្នក ដោយប្រើប៊ូតុងចុចក្នុងផ្ទាំង «MV ខារ៉ាអូខេ» ពេលស្ដាប់។
  មុខងារដែលម៉ូដែលអាចផ្ដល់ឱ្យ (តម្រឹមស្វ័យប្រវត្តិ) មិនត្រូវបានប្រើទេ។
- លទ្ធផលប្រែប្រួលតាម seed — ការរត់មួយទៀតរបស់ខ្ញុំ (seed ផ្សេង) បញ្ចប់សំឡេងនៅវិនាទីទី ~23 ហើយស្ងាត់ ~5 វិនាទីចុងបទ។
- បទនេះបង្កើតដោយ AI ហើយអាជ្ញាបណ្ណម៉ូដែលជា MIT — មើល `../MODEL_REPORT.md` មុនប្រើក្នុងការចេញផ្សាយ។

## ៣. តម្រូវការ

- **Python 3.10+** សម្រាប់ studio (ទាំង Windows / macOS / Linux)
- **FFmpeg ដែលមាន libass** (សម្រាប់ MV អក្សរខ្មែរ)
  - Windows: `winget install Gyan.FFmpeg` · macOS: `brew install ffmpeg` · Linux: `sudo apt install ffmpeg`
  - ពិនិត្យ: `ffmpeg -filters | grep ass` ត្រូវមាន `ass`
- **ម៉ូដែល ACE-Step 1.5** (Python 3.11–3.12, `uv`) — GPU NVIDIA ≥ 4 GB VRAM ណែនាំ (ថាស ~10 GB)។ មាន CPU-only តែយឺតខ្លាំង និងត្រូវការ RAM ច្រើន។
- ជម្រើស៖ **Ollama** (ជំនួយទំនុក) · **Tailscale** (HTTPS សម្រាប់ទូរសព្ទ)

## ៤. ដំឡើង

### ៤.១ ដំឡើង និងបើកម៉ូដែល ACE-Step 1.5 (លើម៉ាស៊ីន GPU)

```bash
# ដំឡើង uv (ម្ដង)           Windows PowerShell: powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
curl -LsSf https://astral.sh/uv/install.sh | sh

git clone https://github.com/ACE-Step/ACE-Step-1.5.git
cd ACE-Step-1.5
uv sync

uv run acestep-api            # REST API នៅ http://127.0.0.1:8001 — លើកដំបូងទាញយកម៉ូដែល ~១០ GB
```

- Windows/macOS មានកញ្ចប់ដំឡើងស្រាប់ — មើល README របស់ ACE-Step។
- VRAM តិច (≤ 6 GB)៖ `ACESTEP_INIT_LLM=false uv run acestep-api` (បិទ LM ផែនការ)។
- GPU នៅម៉ាស៊ីនផ្សេង៖ `ACESTEP_API_HOST=0.0.0.0 ACESTEP_API_KEY=សម្ងាត់ uv run acestep-api` ហើយក្នុង studio កំណត់ `ACESTEP_URL=http://<IP>:8001` និង `ACESTEP_API_KEY`។
- **កុំបើក port 8001 ទៅអ៊ីនធឺណិត**។

### ៤.២ ដំឡើង studio

```bash
cd khmer-ai-music-studio
cp .env.example .env          # កែបើចាំបាច់ (ACESTEP_URL, STUDIO_TOKEN, LLM_MODEL …)
./run.sh                      # Windows: run.bat   — បង្កើត .venv ដំឡើង dependency ហើយចាប់ផ្ដើម
```

dependency មានតែ `fastapi uvicorn python-multipart pillow numpy` (ដំឡើងដោយស្វ័យប្រវត្តិ)។

### ៤.៣ សាកល្បងម៉ូដែលជាមុន (ណែនាំខ្លាំង)

ពេល `acestep-api` កំពុងដំណើរការ៖

```bash
python scripts/check_engine.py --duration 30
```

វានឹង៖ ពិនិត្យ FFmpeg/ពុម្ពអក្សរ/ការភ្ជាប់ម៉ូដែល → ផ្ញើទំនុកខ្មែរ ៤ បន្ទាត់ (`samples/khmer_chorus_4lines.txt`) ទៅម៉ូដែលពិត → បង្ហាញ progress →
រក្សា `data/check_engine/<ពេល>/chorus.wav` + `record.json` → វិភាគសំឡេង (កម្រិត, ផ្នែកស្ងាត់)។ **ស្ដាប់ឯកសារនោះ** ដើម្បីដឹងថាម៉ូដែលច្រៀងខ្មែរបានឬអត់។
ប្រើ `--engine selftest` ដើម្បីសាកល្បងតែប្រព័ន្ធ (មិនមែន AI)។

### ៤.៤ ម៉ូដែលអត្ថបទសម្រាប់ជំនួយទំនុក (ជម្រើស)

```bash
ollama pull qwen3:8b          # ឬម៉ូដែលណាក៏បានដែលអ្នកជឿជាក់លើភាសាខ្មែរ
# ក្នុង .env:   LLM_MODEL=qwen3:8b      (LLM_BASE_URL លំនាំដើម http://127.0.0.1:11434/v1)
```

server ណាក៏បានដែលនិយាយ OpenAI-compatible API (Ollama, llama.cpp, LM Studio, vLLM) ប្រើបាន។ **គុណភាពខ្មែរត្រូវសាកល្បង** — ការណែនាំត្រូវបានបង្ហាញឱ្យអ្នកអាន មិនត្រូវបានជំនួសដោយស្វ័យប្រវត្តិទេ។

## ៥. បើកកម្មវិធី

```bash
./run.sh                # តែកុំព្យូទ័រនេះ  → http://127.0.0.1:8000
./run.sh --lan          # ឱ្យ iPhone/ទូរសព្ទក្នុង Wi-Fi ដូចគ្នាចូលបាន (បង្កើត token + បោះពុម្ព URL)
./run.sh --port 9000    # ប្តូរ port
```

ចុចប៊ូតុងស្ថានភាពម៉ូដែល (ជ្រុងខាងលើស្ដាំ) ដើម្បីមើល៖ ម៉ូដែលណាភ្ជាប់ អាជ្ញាបណ្ណ លក្ខខណ្ឌចេញផ្សាយ តម្រូវការ GPU/VRAM ការគាំទ្រភាសាខ្មែរ និងស្ថានភាព FFmpeg/ពុម្ពអក្សរ។

## ៦. បញ្ជាពី iPhone / ទូរសព្ទ

កម្មវិធី និងម៉ូដែលដំណើរការលើម៉ាស៊ីន GPU។ ទូរសព្ទគ្រាន់តែជាអេក្រង់បញ្ជា។

1. លើម៉ាស៊ីន GPU រត់ `./run.sh --lan` → វាបោះពុម្ព `http://192.168.x.x:8000/?token=…` (និង QR code បើ `pip install qrcode`)។
2. iPhone ត្រូវនៅ **Wi-Fi ដូចគ្នា** → បើក URL នោះក្នុង Safari (token ត្រូវបានរក្សាជា cookie)។
3. ជម្រើស៖ ចុចប៊ូតុងចែករំលែក → **«បន្ថែមទៅអេក្រង់ដើម»** ដើម្បីបើកដូចកម្មវិធី។

សំឡេង/វីដេអូ ដំណើរការលើ iOS ព្រោះ server គាំទ្រ HTTP Range។ **ខ្ញុំមិនទាន់បានសាកល្បងលើ iPhone ពិតទេ** — សូមរាយការណ៍កំហុស។

### ថតសំឡេងពី iPhone ត្រូវការ HTTPS

Safari មិនអនុញ្ញាតមីក្រូហ្វូនលើ `http://192.168.x.x` ទេ។ ជម្រើស (ពីងាយទៅពិបាក)៖

- **ក) Upload ឯកសារ** — ថតដោយ «Voice Memos» ហើយជ្រើសឯកសារក្នុងផ្ទាំងតន្ត្រី (ដំណើរការលើ HTTP)។
- **ខ) Tailscale** (HTTPS មានវិញ្ញាបនបត្រត្រឹមត្រូវ) — ដំឡើង Tailscale លើម៉ាស៊ីន GPU និង iPhone, បើក HTTPS certificates ក្នុង admin console, រួចរត់
  `tailscale serve --bg 8000` ហើយបើក `https://<ឈ្មោះម៉ាស៊ីន>.<tailnet>.ts.net`។ _(ខ្ញុំមិនបានសាកល្បងដោយខ្លួនឯង — ពិនិត្យឯកសារ Tailscale ថ្មីៗ)_
- **គ) វិញ្ញាបនបត្រ self-signed** — `scripts/make_cert.sh <IP-LAN>` បង្កើត `cert.pem`/`key.pem` ហើយ `./run.sh --lan --ssl-certfile cert.pem --ssl-keyfile key.pem`។
  iPhone នឹងព្រមាន — ត្រូវដំឡើង cert ជា profile និងបើកទុកចិត្តក្នុង Settings → General → About → Certificate Trust Settings។ _(server HTTPS សាកល្បងដោយ curl តែមិនបានសាកល្បងលើ iPhone)_

**សុវត្ថិភាព៖** ពេលប្រើ `--lan` ត្រូវតែមាន token (បង្កើតស្វ័យប្រវត្តិ ឬ `STUDIO_TOKEN`)។ កុំបើក port ទៅអ៊ីនធឺណិតដោយគ្មាន HTTPS។

## ៧. របៀបប្រើ (ជំហានខ្លី)

1. **គម្រោងថ្មី** → បិទភ្ជាប់ទំនុក ឬប្រើ «ទំនុកគំរូ ៤ បន្ទាត់»។
2. **ទំនុក** → កែ/បែងចែក Verse·Chorus·Bridge។
3. **តន្ត្រី** → ជ្រើសម៉ូដែល · ស្ទីល · ឧបករណ៍ → ចុច **«សាកល្បង Chorus ខ្លី»** → ស្ដាប់ការបញ្ចេញពាក្យ → ពេញចិត្តហើយចុច **«បង្កើតបទចម្រៀង»**។
   ការងារបង្ហាញស្ថានភាពពិត។ ពេលរួចរាល់ ស្ដាប់ និងទាញយក WAV/MP3 បានភ្លាមក្នុង card។
4. **រូបគម្រប** → នាំចូលរូប ដាក់ចំណងជើង រក្សាទុក (ជាផ្ទៃខាងក្រោយ MV)។
5. **MV ខារ៉ាអូខេ** → ចុចប៊ូតុងធំរាល់ឃ្លា → «មើលស៊ុមពិត» → «YouTube 1920×1080» ឬ «Shorts 1080×1920» → ទាញយក MP4។
6. **បង្ហោះ** → បំពេញព័ត៌មាន → «បង្កើតអត្ថបទ» → ចម្លង។

កំណត់ត្រាសំខាន់៖ ម៉ូដែលអាចបញ្ចប់សំឡេងមុនរយៈពេលដែលបានស្នើ (ក្នុងការសាកល្បងពិតមួយរបស់ខ្ញុំ បទ 28 វិនាទីបញ្ចប់នៅ ~23 វិនាទី; ការរត់ម្ដងទៀតបំពេញស្ទើរពេញ — លទ្ធផលប្រែប្រួលតាម seed) —
កម្មវិធីព្រមាន ហើយ MV កាត់ចុងស្ងាត់ស្វ័យប្រវត្តិ (បិទបាន)។

## ៨. ផ្ទៀងផ្ទាត់ថាពាក្យច្រៀងត្រូវនឹងទំនុកដើម

**វិធីដែលអាចទុកចិត្ត = ស្ដាប់ដោយមនុស្សដែលចេះភាសាខ្មែរ។**

១. **ស្ដាប់ជាមួយទំនុកនៅចំពោះមុខ** — ផ្ទាំងតន្ត្រី → card កំណែ → «ព័ត៌មានលម្អិត» បង្ហាញទំនុកដែលបានផ្ញើពិតៗ។
២. **ផ្ទាំង MV ខារ៉ាអូខេ** ជួយឱ្យស្ដាប់ច្បាស់៖
   - ល្បឿនចាក់ **0.5× / 0.75×** (សំឡេងមិនប្ដូរកម្ពស់);
   - ប៊ូតុង **🔁** ចាក់ឃ្លាមួយម្ដងហើយម្ដងទៀត;
   - ពេលចុចកំណត់ពេលឃ្លា អ្នកនឹងដឹងភ្លាមថាពាក្យដែលឮត្រូវនឹងអក្សរដែលបង្ហាញឬអត់។
៣. សម្រាប់ **ម្ដងមួយបន្ទាត់** សូមកត់៖ ច្បាស់ / ពាក់កណ្ដាល / មិនច្បាស់។
៤. បើមិនច្បាស់៖ សាកល្បង `vocal_language` = `unknown` ↔ `km` · ប្តូរ seed · ធ្វើឃ្លាឱ្យខ្លី មានចន្លោះរវាងឃ្លាតូច ·
   ម៉ូដែល HeartMuLa · ឬ **ថតសំឡេងខ្លួនឯង** លាយជាមួយភ្លេងសុទ្ធ (មានក្នុងកម្មវិធី)។

**ការពិនិត្យស្វ័យប្រវត្តិ (ពិសោធន៍ — កុំជឿ)៖** `pip install faster-whisper` រួច

```bash
python scripts/verify_lyrics.py data/check_engine/<ពេល>/chorus.wav --lyrics samples/khmer_chorus_4lines.txt --model large-v3 --lang km
```

⚠️ ក្នុងការសាកល្បងរបស់ខ្ញុំ Whisper large-v3 ស្ដាប់បទពិតបាន «ខុស 86%» និង «ខុស 130%» (ពីរបទ) **ប៉ុន្តែស្ដាប់សំឡេងនិយាយខ្មែរស្អាតនៃទំនុកដដែលក៏ «ខុស 80%»** ដែរ។
ដូច្នេះឧបករណ៍នេះ **មិនអាចបញ្ជាក់ថាត្រូវ ឬខុសបានទេ** — មានតែសូចនាករទាបប៉ុណ្ណោះ។
